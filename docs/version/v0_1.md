# Versión v0.1 — MVP

**Estado:** versión MVP en desarrollo, preparada para revisión y push.
**Revisión:** 2026-09-26.

## Trabajo incluido

- Dashboard con estadísticas de jornada y acumulados globales.
- Gestión de jornadas, autores y artículos; datos de jornada temporales en memoria.
- Órdenes con varias líneas, cantidades enteras y precios por artículo. Los subtotales y totales se calculan en el backend.
- Conteo de ventas por autor, artículo y categoría, sin inventario inicial.
- Registro de acciones y exportación JSON al cerrar una jornada.
- Acumulados globales persistidos en un archivo JSON local.
- Interfaz HTML/CSS renderizada por FastAPI, con confirmaciones diferenciadas para cerrar y descartar.

## Stack fijado

- Python 3.13.5.
- FastAPI 0.140.13 y Uvicorn 0.52.4.
- HTML y CSS; pytest 9.0.3 para validación.
- Dependencias fijadas en `requirements.txt`.

## Límites conocidos

- La jornada activa, autores, artículos, órdenes, eventos y última exportación se pierden al reiniciar el proceso.
- No hay autenticación ni permisos persistentes para supervisor.
- No se implementa inventario inicial. CSV y MariaDB quedan para futuras etapas.
- La descarga al cerrar se inicia desde la página de resultado; si el navegador no la inicia automáticamente, hay un enlace para repetirla.
