# v0.3 — En desarrollo

Actualización UTC: 2026-10-14T14:26:59Z.

El primer bloque incorpora persistencia local por acción y recuperación de la
última jornada mediante rollback. La aplicación y la API se identifican como 0.3;
el documento de exportación conserva el esquema v0.2 compatible.

- Ruta única `DATA_DIR`, revisiones coordinadas, copia anterior y restauración tras reinicio.
- Artículos nuevos persistentes y precios hacia adelante; órdenes abiertas editables.
- Recuperación del estado previo al cierre, con descarte confirmado de la jornada abierta.
- Catálogo vigente conservado, acumulados revertidos y nuevo cierre sin duplicación.
- Descargas disponibles después del nuevo cierre y protección por ID de cierre.
- Historial operativo persistente, eventos pendientes y diagnóstico ante corrupción.

Consultar [persistencia y recuperación](../PERSISTENCIA.md).
El segundo bloque agrega [logging configurable](../LOGGING.md), INFO/DEBUG,
rotación y diagnóstico seguro de errores. El tercer bloque agrega
[healthcheck](../HEALTHCHECK.md) de datos y escritura, con script HTTP y reintentos.
El cuarto bloque incorpora [seguridad local](../SEGURIDAD.md): límites de entrada,
protección de formularios, comprobación de host y origen, cabeceras y errores seguros.
El quinto bloque incorpora [plantillas e interfaces propias](../FRONTEND.md),
con serie y numeración manuales. El sexto bloque prepara Docker multiarquitectura y montaje configurable. El
[ADR de seguridad](../decisions/ADR-005-seguridad-local-y-escalabilidad.md) establece
las condiciones futuras para red local y nube; el [ADR-006 de frontend](../decisions/ADR-006-jinja2-e-interfaces-de-ordenes.md)
documenta Jinja2 y nuevas interfaces. Los ADR-007, ADR-008 y ADR-009 documentan Docker, logging y persistencia.
La validación de este bloque se registra en [informes de pruebas](../tests/README.md).
