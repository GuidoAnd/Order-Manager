## Reproducción

Instalar `requirements-test-dev.txt`, descargar Chromium con
`python -m playwright install --only-shell chromium` y ejecutar `pytest -q`.
El navegador requiere bibliotecas y fuentes de sistema. En este entorno mínimo
se prepararon localmente para la ejecución; no forman parte del repositorio.
