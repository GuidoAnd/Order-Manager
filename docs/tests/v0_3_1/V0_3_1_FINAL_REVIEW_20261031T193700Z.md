## Límites y cierre

Las solicitudes de prueba se resuelven por ASGI sin abrir puertos. El adaptador
Chromium sigue redirecciones internamente: permite comprobar flujos y geometría,
pero no reproduce fielmente todo el historial HTTP de un navegador real. No se
acreditan dispositivos físicos, otros motores, conectividad LAN ni el error
exacto de caché informado. No se atribuye una causa demostrada a la desaparición
completa de una orden que no se reprodujo; sí se verifican las protecciones
contra sobrescritura de formularios antiguos y duplicación por reenvío.

Esta ejecución no es una prueba de carga ni una auditoría de seguridad independiente.
Las pruebas de fallos simulados no garantizan todos los fallos físicos del disco.
La construcción y ejecución Docker corresponden al administrador y no forman
parte de esta suite. Se mantiene una instancia y un worker, sin autenticación
ni control obligatorio de versiones para todas las escrituras JSON de la API.

v0.3.1 queda cerrada documentalmente con este resultado y su
[resumen de versión](../../version/v0_3_1.md). La publicación en Git es una
operación posterior y no forma parte de esta validación.
