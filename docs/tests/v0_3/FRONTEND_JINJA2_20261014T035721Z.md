## Resultado

Suite completa: **437 PASS**, sin fallos, en **282,66 s**.
Incluye **26 casos nuevos**: 21 de reglas, interfaces y recuperación, más
5 de navegación y edición en Chromium. Viewports: 320x568, 375x667, 430x932,
768x1024 y 1366x768.

## Alcance

- Series 10/20, extremos inclusivos, rechazos fuera de rango y formato inválido.
- Repeticiones entre órdenes y autores, número manual y ausencia de avance automático.
- Edición con el mismo ID y contador interno; valores y contexto conservados.
- Reinicio, JSON de cierre y recuperación exacta mediante rollback.
- Detección de series inválidas en estado persistido y lectura de órdenes históricas.
- API con campos manuales obligatorios y errores sin entradas completas.
- Listado sin editor, creación y edición con rutas propias, redirección de enlaces
  anteriores, cancelación hacia Dashboard y errores asociados al campo.
- Finalización de Jornada antes de Autores y acciones vigentes de Artículos.
- Escape de datos, reutilización de plantillas y actualización del negocio entre peticiones.
- Navegador sin JavaScript: creación, error, edición, cancelación y disposición móvil.
- Regresiones existentes: inventario, precios, órdenes facturadas/no facturadas,
  autores, búsqueda, paginación, estadísticas, exportaciones, persistencia,
  corrupción, logging, healthcheck y controles de seguridad.

## Ejecución

```bash
PYTHONDONTWRITEBYTECODE=1 .venv/bin/python -m pytest -q -p no:cacheprovider --tb=short
```

Se reutilizó la configuración de fuentes existente para Chromium. El adaptador
ASGI sirve las respuestas sin abrir puertos.

Verificaciones adicionales: 39 plantillas compiladas, compilación Python,
`pip check`, formato de diff y enlaces locales públicos: PASS.
Jinja2 3.1.6 y MarkupSafe 3.0.3 instalados exclusivamente en el entorno virtual;
ninguna dependencia existente se actualizó.

## Límites

Chromium emulado; no acredita dispositivos físicos ni otros motores.
La validación funcional no mide rendimiento bajo carga ni establece porcentajes
de mejora. La aplicación mantiene una instancia y un worker, sin autenticación.
