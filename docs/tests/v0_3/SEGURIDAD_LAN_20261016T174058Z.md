# Acceso LAN temporal — v0.3

Fecha UTC: **2026-10-16T17:40:58Z**. Resultado: **PASS**.

## Cambio validado

`ALLOWED_HOSTS` admite IP o nombres exactos adicionales del servidor, conserva
loopback y se valida antes de abrir el almacenamiento. `APP_BIND_HOST` configura
la publicación de Compose; su valor predeterminado continúa siendo `127.0.0.1`.
La excepción se retira mediante configuración y reinicio, conservando los datos.
Se mantienen origen exacto, tokens de formulario, límites, cabeceras y un worker.
No se incorpora autenticación ni control de conflictos entre ediciones.

## Método y alcance

Las solicitudes pasan directamente a ASGI con datos temporales. Chromium y las
bibliotecas de pruebas son los existentes; no se abrieron puertos ni se accedió
a equipos de la red. Los contextos emulados no acreditan dispositivos físicos,
conectividad LAN real ni edición simultánea con detección de conflictos.
La revisión de Compose comprueba JSON y configuración declarada. La construcción
y ejecución de las imágenes corresponden al administrador.

Comando portable equivalente de suite completa, con Chromium disponible:

```bash
lan_test_data_dir="$(mktemp -d)"
```
