## Alcance

- Formularios con token válido, inválido, duplicado y anterior al reinicio.
- Origen distinto, otro puerto, origen nulo y solicitudes cross-site.
- API JSON local y rechazo de formatos de formulario o texto plano.
- Hosts locales IPv4/IPv6 y rechazo de hosts externos o ambiguos.
- Cuerpos excesivos con y sin Content-Length; detención durante recepción y
  aceptación del límite exacto. Cabeceras y campos duplicados.
- Validación común de textos, caracteres de control, límites de taxonomía,
  búsquedas, URL, codificación inválida y Unicode admitido.
- Rechazos sin cambios en memoria, revisión y archivos de negocio.
- Errores sin entradas completas y cabeceras en respuestas normales,
  rechazos y errores internos. Escape HTML y bloqueo de scripts mediante CSP.
- Flujos existentes de inventario, autores, órdenes, resultados, cierre,
  descarte, rollback, reinicio, corrupción, logging, healthcheck y exportaciones.

## Ejecución

```bash
PYTHONDONTWRITEBYTECODE=1 .venv/bin/python -m pytest -q -p no:cacheprovider --tb=short
```

Chromium emulado mediante el adaptador ASGI existente, sin abrir puertos ni
instalar dependencias. Compilación Python, formato de diff y enlaces locales
de documentación pública verificados.

## Límites

No acredita dispositivos físicos ni otros motores de navegador. La aplicación
continúa sin autenticación y requiere una instancia y un worker. No se habilitó
acceso LAN, nube, infraestructura ni múltiples escritores. Los requisitos de
evolución se establecen en el
[ADR de seguridad](../../decisions/ADR-005-seguridad-local-y-escalabilidad.md).
